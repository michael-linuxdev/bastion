- `bauen.ts` – Ereignis `bau`, Projektion `bastion`: beginnen, abbrechen, versetzen, Bauschritte (DATENMODELL §4.4)
- `wissen.ts` – Rolle „Wissen“ (Bastion: Studierstube): Bücher für gefestigte Kompetenzen aus den Bauplan-Buchungen (B-6)
- `epoche.ts` – Ziel und Ende der Epoche 1 (BASEBAU §5.4)

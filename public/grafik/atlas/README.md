# Atlas (GRAFIK-SPRITES.md, G5/G10)

Pfadschema: `{thema}/e{1–4}/{rolle}_s{stufe}` – siehe `atlasId` in `src/ui/bastion/grafik/atlas.ts`.

Ohne `manifest.json` zeichnet die App den Code-Fallback; ab Epoche 2 wächst die Optik
über `epoche-optik.ts` (Höhe, Stein-Farbton, Einfassung). Sprites können parallel erzeugt
und hier eingehängt werden.
